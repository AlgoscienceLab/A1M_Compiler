## Register File

```
┌─────────────────────────────────────┐
│      Register File (32 x 64-bit)    │
├─────────────────────────────────────┤
│  R0   : 0x0000000000000000  (ZERO)  │ ◄─── Hardwired to 0
│  R1   : 0x________________          │
│  R2   : 0x________________          │
│  R3   : 0x________________          │
│  ...                                │
│  R30  : 0x________________          │
│  R31  : 0x________________  (LR)    │ ◄─── Link Register
├─────────────────────────────────────┤
│  PC   : 0x0000000000001000          │ ◄─── Program Counter
│  SP   : 0x7FFFFFFFFFFFFFF0          │ ◄─── Stack Pointer
│  FLAGS: 0x0000000000000000          │ ◄─── Status Flags
│         [N][O][C][Z]                │      (Neg,Ovf,Cry,Zero)
└─────────────────────────────────────┘
```

## Instruction Formats

```
┌─────────────────────────────────────────────────────────────┐
│                  32-bit Instruction Formats                  │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  R-Type (Register):                                         │
│  ┌────────┬─────┬─────┬─────┬─────────┐                    │
│  │ opcode │ rd  │ rs1 │ rs2 │  func   │                    │
│  │ 8 bits │5bit │5bit │5bit │  9 bits │                    │
│  └────────┴─────┴─────┴─────┴─────────┘                    │
│   31   24  23 19 18 14 13  9  8      0                     │
│                                                              │
│  I-Type (Immediate):                                        │
│  ┌────────┬─────┬─────┬──────────────┐                     │
│  │ opcode │ rd  │ rs1 │  immediate   │                     │
│  │ 8 bits │5bit │5bit │   14 bits    │                     │
│  └────────┴─────┴─────┴──────────────┘                     │
│   31   24  23 19 18 14 13           0                      │
│                                                              │
│  J-Type (Jump):                                             │
│  ┌────────┬────────────────────────────┐                   │
│  │ opcode │        address             │                   │

│  └────────┴────────────────────────────┘                   │

│                                                              │
```

## Data Flow Example (ADD R1, R2, R3)

```
┌──────────────────────────────────────────────────────────┐
│              ADD R1, R2, R3 Execution                     │
├──────────────────────────────────────────────────────────┤
│                                                           │
│  1. Fetch:     PC → Inst Memory → Instruction           │
│                0x02088000 (ADD opcode=0x02)              │
│                                                           │
│  2. Decode:    Reg[R2] → Operand A (0x0000000000000005) │
│                Reg[R3] → Operand B (0x0000000000000003) │
│                Control: RegWrite=1, ALUOp=ADD            │
│                                                           │
│  3. Execute:   ALU: 0x05 + 0x03 = 0x08                  │
│                Flags: Z=0, C=0, O=0, N=0                 │
│                                                           │
│  4. Memory:    (No memory access)                        │
│                                                           │
│  5. Writeback: 0x08 → Reg[R1]                           │
│                                                           │
└──────────────────────────────────────────────────────────┘
```
