# Algo Programming Language Compiler

The Algo compiler translates Algo source code (.algo files) into A1M assembly language.

## Features

### Supported Types
- `int` - 64-bit signed integer
- `float` - 32-bit IEEE 754 floating-point
- `double` - 64-bit IEEE 754 floating-point  
- `bool` - Boolean (0 or 1)
- `char` - 8-bit character
- `void` - No return value
- `string` - String type (limited support)

### Control Structures
- `if` / `else if` / `else` - Conditional branching
- `while` - Pre-test loop
- `do-while` - Post-test loop
- `for` - Counter-controlled loop
- `switch` / `case` / `default` - Multi-way branch
- `goto` - Unconditional jump with labels
- `break` / `continue` - Loop control
- `return` - Function return

### Operators

**Arithmetic**: `+`, `-`, `*`, `/`, `%`  
**Increment/Decrement**: `++`, `--` (prefix and postfix)  
**Compound Assignment**: `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `|=`, `^=`, `<<=`, `>>=`  
**Comparison**: `==`, `!=`, `<`, `>`, `<=`, `>=`  
**Logical**: `&&`, `||`, `!`  
**Bitwise**: `&`, `|`, `^`, `~`, `<<`, `>>`  
**Ternary**: `? :`  
**Special**: `sizeof`

### Language Features
- Function declarations with type annotations
- Variable declarations with `let` keyword
- Enumerations with `enum`
- Type annotations: `variable: type`
- Return type annotations: `-> type`
- Compile-time constants with enums

## Building

```bash
cd compiler
make
```

This creates the `algo-compiler` executable.

## Usage

```bash
./algo-compiler input.algo -o output.asm
```

### Options
- `-o <file>` - Specify output assembly file (default: `out.asm`)
- `-h` - Show help message

## Example

**Input** (`hello.algo`):
```algo
func main() -> void {
    let x: int = 42;
    let pi: float = 3.14159f;
    let e: double = 2.718281828459045;
    
    print(x);
}
```

**Compile**:
```bash
./algo-compiler hello.algo -o hello.asm
```

**Output** (`hello.asm`):
```assembly
; Generated by A1M Algo Compiler
.text

main:
    MOVI R1, 42
    MOVI R2, 1078530000    ; float 3.141590
    MOVI R3, 4614256656552045848    ; double 2.718282
    MOVI R4, 0
    ADD R4, R4, R1
    SYSCALL 0x01
    MOVI R4, 0
    SYSCALL 0x00
```

## Floating-Point Support

### Float Literals
```algo
let f1: float = 3.14f;           // Explicit float suffix
let f2: float = 1.5f;
let f3: float = 2.0e10f;         // Scientific notation
let f4: float = 1.23e-5f;        // Negative exponent
```

### Double Literals
```algo
let d1: double = 3.14159265;     // No suffix (default)
let d2: double = 2.71828d;       // Explicit double suffix
let d3: double = 1.0e100;        // Large exponent
let d4: double = 1.23e-100;      // Very small number
```

### IEEE 754 Representation
- **Float**: Stored as 32-bit IEEE 754 in lower bits of 64-bit register
- **Double**: Stored as 64-bit IEEE 754 in full register
- Values are stored with bit-exact representation
- Assembly comments show original decimal value

### Current Limitations
⚠️ **Arithmetic operations on float/double are not yet implemented**

You can:
- ✅ Declare float/double variables
- ✅ Store literal values
- ✅ Pass to functions
- ✅ Use in `sizeof` operator

You cannot (yet):
- ❌ Perform arithmetic (+, -, *, /)
- ❌ Compare values (<, >, ==)
- ❌ Cast between types

Future implementation will require either:
1. Hardware FPU (Floating Point Unit)
2. Software floating-point library
3. Hybrid approach

## Syntax Reference

### Variable Declaration
```algo
let variable_name: type = value;
```

### Function Definition
```algo
func function_name(param1: type1, param2: type2) -> return_type {
    // function body
}
```

### Enum Declaration
```algo
enum Status {
    OK = 0,
    ERROR = 1,
    PENDING = 2
}
```

### Control Flow
```algo
// If-else
if (condition) {
    // code
} else if (another_condition) {
    // code
} else {
    // code
}

// While loop
while (condition) {
    // code
}

// Do-while loop
do {
    // code
} while (condition);

// For loop
for (init; condition; increment) {
    // code
}

// Switch-case
switch (expression) {
    case 1:
        // code
        break;
    case 2:
        // code
        break;
    default:
        // code
        break;
}

// Goto
start:
    // code
    if (condition) {
        goto start;
    }
```

## Implementation Details

### Compiler Stages
1. **Lexer** - Tokenizes source code
2. **Parser** - Builds Abstract Syntax Tree (AST)
3. **Code Generator** - Emits A1M assembly

### Files
- `src/lexer.c` - Lexical analysis
- `src/parser.c` - Syntax analysis and AST construction
- `src/codegen.c` - Assembly code generation
- `include/compiler.h` - Type definitions and declarations

### Symbol Table
- Tracks variables, functions, and constants
- Register allocation
- Scope management
- Type checking

### Register Usage
- R0: Always zero (by convention)
- R1-R31: General purpose registers
- Return values in R1
- Function arguments in sequential registers
